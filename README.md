# LG B2B 공식인증점 글로벌 · 네이버 SA 리포트

`data` 폴더에 CSV를 올리면 GitHub Actions가 대시보드를 다시 만들어 Pages 주소에 자동으로 반영합니다(1~2분).

## 데이터 올리는 법

1. GitHub 저장소에서 `data` 폴더로 들어갑니다.
2. **Add file → Upload files** 로 CSV를 끌어다 놓고 **Commit changes** 를 누릅니다.
3. 상단 **Actions** 탭에서 "대시보드 자동 업데이트"가 초록색 체크가 되면 끝입니다.

올릴 수 있는 파일 (열 이름을 보고 종류를 자동으로 알아봅니다, 파일 이름은 상관없음)

| 종류 | 네이버에서 받는 곳 | 꼭 있어야 하는 열 |
|---|---|---|
| 매체 보고서 | 보고서 → 매체 보고서 (**일별** 포함) | 일별, 캠페인유형, 캠페인, 광고그룹, 매체이름, 검색/콘텐츠 매체, 검색어, 검색 유형, 노출수, 클릭수, 총비용, 평균노출순위, 구매완료 전환수, 구매완료 전환매출액(원) |
| 소재 보고서 | 보고서 → 소재 단위 (일별을 넣으면 기간 필터가 적용됨) | 캠페인, 광고그룹, 소재, 노출수, 클릭수, 총비용, 평균노출순위, 구매완료 전환수, 구매완료 전환매출액(원) |
| 상품 매칭 | 광고 다운로드 (쇼핑검색 소재) | 소재 ID, 기본상품명 (노출상품명·카테고리는 있으면 사용) |

- 기간이 다른 매체 보고서를 여러 개 올려도 됩니다. 같은 날짜가 겹치면 **기간이 더 늦게 끝나는 파일** 것을 씁니다.
- 지난 파일을 지울 필요는 없습니다. 잘못 올린 파일은 지우고 다시 커밋하면 됩니다.
- 업체명은 `config.json` 에서 바꿉니다.

## 처음 한 번 설정

**Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.

## 주의

공개 저장소라면 `data` 폴더의 원본 CSV(상품 매칭 파일의 로그인 ID 포함)와 Pages 주소 모두 누구나 볼 수 있습니다.
